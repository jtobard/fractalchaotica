# Fractal Chaotica

A simple fractal visualizer written in Java (Swing).
This project allows you to visualize different types of fractals such as Mandelbrot, Julia, Lambda, and Biomorph.

## Requirements

- Java 11 or higher

## Build and Run

The project uses Gradle.

### To compile and run tests:

```bash
./gradlew build
```

### To run the application:

```bash
./gradlew run
```

Or if you prefer to generate an executable jar:

```bash
./gradlew installDist
./build/install/fractalchaotica/bin/fractalchaotica
```
